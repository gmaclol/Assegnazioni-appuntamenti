# Istruzioni Progetto

## Regole di sistema per i Tool
- La tua cartella di lavoro corrente è L'UNICA in cui devi operare.
- Quando usi i tool di lettura/scrittura (Read, Edit, Write, LS), usa SEMPRE e SOLTANTO percorsi relativi rispetto alla cartella corrente (es. `./start.md`, `./src/main.kt`).
- NON usare MAI percorsi assoluti, NON usare MAI la cartella `.claude` o `/path/to/`.
